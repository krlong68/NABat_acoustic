# sonobat_txt

This directory contains TXT files that were output from the SonoBat analysis
software. The files should be organized as follows:

```
sonobat_txt/
├── Survey_Year/
│   └── Grid_ID/
│       └── Sonobat_ouput.txt
└── README.md
```

The above subdirectory and file names will be replaced to suit your files.
Example below: the survey was performed in 2025 and the grid ID was 113851.

```
sonobat_txt/
├── 2025/
│   └── 113851/
│       ├── Session_20250828-Attributed.txt
│       └── Session_20250829-Attributed.txt
└── README.md
```
